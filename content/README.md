# DistroNow content strategy library

This folder is the durable home for the content strategy knowledge that used
to live in the local prototype experiments. It is intentionally separate from
generated project content: these are reusable rules, patterns, prompts, and
review systems that should improve every brand workspace.

The in-app reading experience is available at:

```text
/projects/[id]/content-library
/projects/[id]/blueprint
```

## Contents

- `strategies/content-mix.md` — Growth, Trust, Conversion planning;
- `strategies/hooks-angles-formats.md` — idea generation system;
- `strategies/virality.md` — question hooks and safe testing;
- `strategies/lead-magnets.md` — comment-to-email conversion path;
- `strategies/characters-and-ugc.md` — repeatable creator and UGC production;
- `strategies/slideshows.md` — carousel creation and QA;
- `strategies/niche-validation.md` — finding useful, monetizable content spaces;
- `strategies/publishing-loop.md` — turning content into account decisions.

These files are source knowledge for future editable Strategy Library records;
they are not a replacement for project-specific brand and customer decisions.
