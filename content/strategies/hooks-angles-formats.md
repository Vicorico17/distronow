# Hooks, angles, and formats

Every content idea should choose one item from each layer:

```text
customer problem → hook → angle → format → proof → CTA
```

## Hook patterns

- Pain specificity: name the exact lived moment.
- Result first: lead with the outcome and reveal the mechanism.
- Contrarian position: challenge the belief keeping the audience stuck.
- Proof first: open with a result, then show how it happened.
- Before/after: make the transformation visible.
- Cost of inaction: quantify what the current behavior costs.
- Stop doing this: identify one concrete mistake.
- Nobody tells you: open a useful curiosity gap.
- Raw emotion: show the honest before-state without manufacturing drama.

## Creative angles

- Pain amplification;
- benefit stack;
- hidden mechanism;
- objection handling;
- proof breakdown;
- old way versus new way;
- common mistake;
- customer lens: before-state, decision moment, after-state.

## Formats

- UGC creator-to-camera;
- POV workflow;
- founder POV;
- screen demo;
- testimonial;
- comparison;
- listicle;
- story.

Choose the format that makes the proof easiest to see. Adapt the same idea per
platform instead of blindly cross-posting identical content.
